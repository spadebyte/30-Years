# 군수의 30년

소멸 고위험 군의 군수가 되어 2025년부터 2055년까지 스마트 기술 예산을 나누고, 중요한 순간마다 결정을 내리는 인구 시뮬레이션 게임입니다. 2026 지식 융합 프로젝트(키워드: 지역 소멸·도시 재생, 주제: 스마트 시티 도입을 통해 지역 소멸을 어떻게 늦출 수 있을까?)의 산출물입니다.

## 실행

```bash
python -m http.server 8765 --directory game
```

브라우저에서 `http://localhost:8765`를 열면 됩니다.

## 구성

| 경로 | 내용 |
|---|---|
| `game/index.html` | 게임 화면 |
| `game/engine.js` | 인구 모델 (게임과 검증이 같은 코드를 씀) |
| `game/choices.js` | 선택 이벤트 8개와 근거 |
| `game/art.js` | 선택 이벤트 삽화 (코드로 그린 SVG) |
| `game/tour.js` | 처음 안내 화면 |
| `game/explain.html` | 출처와 원리 (원리 애니메이션, 정확도 검증, 가정과 출처) |
| `game/gamedata.js` | 모델 값과 검증 결과 (`model/build_game.js`로 만듦) |
| `model/` | 데이터 정리, 백테스트, 점검 스크립트 |
| `data/` | 행정안전부 주민등록 인구(2010~2025) 원자료, 전북 시군 장래인구추계(공식) |

## 모델 요약

- 전북 소멸 고위험 7개 군(진안·무주·장수·임실·순창·고창·부안)의 주민등록 인구로 나이대별 '1년 뒤 남는 비율'과 출생을 계산합니다.
- 과거 자료로 맞추고 이미 지나간 해를 예측해 검증했습니다: 5년 예측 오차 2.8%, 처음 보는 군 3.1%.
- 정책 효과는 사례(스마트팜 정착, 농촌유학 정주율 등)에 맞춘 가정값입니다.
- 이동 가정은 '지금 추세'(기본)와 '공식 추계'(전북 공식 장래인구추계처럼 들어오는 사람 증가) 중에서 고를 수 있습니다.

## 데이터 다시 만들기

```bash
cd model
python build_data.py
node backtest.js
node build_game.js
```
